# 윈도우 최상위 모니터링 프로그램 개발 언어 선정 분석 보고서

윈도우 환경에서 "Always on Top"(최상위 노출) 상태를 유지하며 실시간 데이터를 모니터링하는 프로그램을 개발하기 위해, 성능, UI 구현 용이성, 시스템 접근성을 기준으로 언어 및 프레임워크를 분석합니다.

## 1. 후보 기술 스택 비교

### C# (WPF / WinUI 3)

- **장점**: 윈도우 네이티브 API(Win32) 접근이 매우 용이합니다. `Topmost="True"` 속성 하나로 최상위 노출이 가능하며, 투명도 조절(`AllowsTransparency`)이나 마우스 클릭 관통(Click-through) 구현이 간단합니다. XAML을 통해 프리미엄한 UI 디자인을 구현할 수 있습니다.
- **적합성**: 윈도우 전용 강력한 시스템 유틸리티를 원할 때 최상의 선택입니다.

### JavaScript/TypeScript (Electron)

- **장점**: 웹 기술(React, Vue, HTML/CSS)을 그대로 사용하여 화려하고 역동적인 UI를 가장 빠르게 만들 수 있습니다. 오픈소스 라이브러리가 매우 풍부합니다.
- **단점**: 단순 모니터링 툴치고는 메모리 점유율이 높습니다. (Chromium 기반)
- **적합성**: 복잡한 대시보드를 시각화하고 웹 개발 경험을 살리고 싶을 때 좋습니다.

### Rust (Tauri)

- **장점**: Rust의 안정성과 웹 기반 UI(Chromium 대신 시스템 웹뷰 사용)를 결합하여 매우 가볍습니다. 실행 파일 크기가 작고 보안성이 뛰어납니다.
- **적합성**: 저사양 PC에서도 가볍게 돌아가는 고성능 모니터링 툴을 지향할 때 추천합니다.

### Python (PyQt / PySide)

- **장점**: 데이터 처리 로직(Pandas, NumPy 등)이 포함된 모니터링이라면 로직 구현이 매우 빠릅니다.
- **단점**: 패키징(exe 제작) 후 용량이 크고 디자인 자유도가 C#이나 웹 기술에 비해 다소 떨어집니다.

## 2. 최종 추천 및 사유

**추천: C# (WPF) 또는 Tauri (Rust + Web)**

- **프리미엄 디자인과 윈도우 밀착 기능**을 원하신다면 **C# (WPF)**를 가장 추천합니다. `ModernWpf`나 `MaterialDesignInXaml` 같은 라이브러리를 사용하면 윈도우 11 스타일의 깔끔하고 세련된 디자인을 쉽게 뽑아낼 수 있습니다.
- 만약 **성능 최적화와 가벼운 실행 파일**이 더 중요하다면 **Tauri**가 좋은 대안입니다.
